## About

I build AI systems, desktop tools, and data-driven applications. My current interests include multi-agent workflows, local-first software, computer vision, and full-stack product development.

## Personal projects

### [AQG Studio](https://github.com/Anshuman791322/aqg-studio)

An automated question-generation platform that uses a multi-agent LangGraph pipeline to turn educational documents into grounded assessments. It includes document processing, RAG-based generation, automated evaluation, human review, and exports for Moodle XML, QTI, PDF, DOCX, JSON, and CSV.

`Python` `FastAPI` `LangGraph` `Next.js` `PostgreSQL` `Supabase`

### [JARVIS Windows Local](https://github.com/Anshuman791322/Ai-agent)

A Windows-first, local-first desktop assistant with a native PySide6 interface, local Ollama reasoning, faster-whisper speech recognition, SQLite memory, voice activation, routines, and policy-based action controls.

`Python` `PySide6` `Ollama` `Whisper` `SQLite`

### [Personal portfolio](https://anshuman791322.github.io)

My portfolio website, built with Next.js and TypeScript and deployed through GitHub Pages.

`TypeScript` `Next.js` `React`

### [Classifying Periodic Variable Stars](https://github.com/Anshuman791322/periodically-variable-stars)

A machine learning project using Gaia DR3 photometry to classify RR Lyrae, Cepheids, long-period variables, and eclipsing binaries.

`Jupyter Notebook` `Machine Learning` `Astronomical Data`

### [Smart Driver Monitoring Dashboard](https://github.com/Anshuman791322/smart-driver-monitoring-dashboard-downloads)

A public Android APK distribution repository for a driver-monitoring dashboard.
