# Project typefaces

- **Chakra Petch SemiBold** is the project title face. Its squared letterforms fit the existing anime and technology artwork.
- **Manrope Medium** is the description and metadata face. Its open shapes keep the summaries readable at profile size.

Both families come from [Google Fonts](https://github.com/google/fonts). Their SIL Open Font Licenses are included beside the files. `Manrope-Medium.ttf` is a static instance at weight 500 of the supplied variable font.

The SVG builder converts only used glyphs to shared paths. Visitors do not need these fonts installed and make no external font requests. Complete descriptions are also retained in Markdown and in SVG accessibility descriptions.
